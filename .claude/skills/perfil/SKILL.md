# Perfil · a consultora

Quem chega no seu perfil decide em segundos se segue. Esta skill olha o perfil como essa visita e diz o que trocar.

## 1. O que pedir

Print do perfil (melhor) **ou** o texto de: nome, @, bio, link, nomes dos destaques e os 3 posts fixados (sobre o quê é cada um).
Leia também `~/.claude/time-de-conteudo/marca.md` (público e ação desejada). Sem ele, faça o onboarding descrito na skill `reel` (seção "Marca").
Não invente número de seguidores, resultado nem depoimento.

## 2. Auditoria (nota 0, 1 ou 2 por item, com 1 linha de motivo)

| Item | O que é 2 |
|---|---|
| Foto | rosto ou logo legível em miniatura |
| Nome | tem a palavra que o cliente busca ("Ana · Nutri esportiva"); o campo nome entra na busca |
| @ | fácil de falar e escrever, sem números ou pontos sobrando |
| Bio | diz **pra quem** + **o que resolve** + **prova** (se houver) + **o que fazer agora**, em até 150 caracteres |
| Link | leva a uma ação só (agendar, comprar, material gratuito) |
| Destaques | poucos, na ordem: quem sou → provas → como comprar/agendar |
| Fixados | 3 papéis: o melhor post de alcance, uma prova, a oferta ou o "comece por aqui" |
| Primeira grade | as 9 primeiras imagens deixam claro o assunto do perfil |

Some e dê o placar (x/16) e **as 3 trocas que mais mudam o jogo**, em ordem.

## 3. Reescrita

- **3 bios** (até 150 caracteres cada, conte), com ângulos diferentes: resultado, identificação ("pra quem…"), autoridade. Uma ação no final apontando pro link ou pro direct.
- **Nome** com palavra-chave (2 opções).
- **Destaques:** nomes curtos e a ordem.
- **Fixados:** qual post fixar em cada um dos 3 papéis (ou que post criar, se faltar).

## 4. Entrega

Tabela da auditoria → as 3 trocas → bios → nome → destaques → fixados. Curto e direto, pronto pra aplicar no app.
